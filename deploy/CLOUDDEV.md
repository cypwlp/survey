# 云开发（CloudBase）部署手册 —— 固定 19.9 元/月那条路

> 一句话：**后端从「自己那台服务器 + 443 端口」搬到「微信自己的云」**
> 原来的麻烦（外网只开 80、443 不通、动态公网 IP、备案、端口映射）**全部消失**，
> 因为小程序调云函数走的是微信自家内网通道，不需要域名、不需要端口、也不需要公网 IP。

---

## 0. 这个方案长什么样

```
小程序页面
  └─ wx.cloud.callFunction({name:'osurvey', ...})     ← 微信内网，不走公网
        └─ 云函数 osurvey（Node.js，就是 cloudfunctions/osurvey/）
              ├─ router.js   路由（路径与原来的 REST 一模一样）
              ├─ db.js       读写云数据库
              └─ 云数据库（集合 survey / answer / visit / survey_group / group_name）
```

* 原来的 Express 后端（server/）**留着不删**：可以随时把配置切回去当备用。
* 小程序端只换了「传输方式」，页面代码一行没改（utils/api.js 里包了三选一的通道）。

## 1. 开通云开发（免费，先不花钱）

1. 打开**微信开发者工具**，**用仓库根目录当项目目录**：
   `D:\WORK\Survey-System`（**不是** `miniprogram` 子目录——云函数在 `cloudfunctions/`，只有打开根目录才看得到）
   > 之前一直打开 `miniprogram` 子目录的话，这次换成根目录即可；appid 不用重填。
2. 点工具栏的 **「云开发」** 按钮 → 首次会弹开通页 → 同意并开通。
3. 建环境：名称随意（建议 `osurvey`），套餐先选**免费体验环境**（小程序未上线前不收费）。
4. 开通后记下**环境 ID**（在云开发控制台左上角的环境下拉框 / 设置里）。本项目实际用的环境：
   **`cloud1-d2g83jh3td8664c67`**（微信体验版，2026-10-17 建）。

---

## 2. 把环境 ID 填进小程序配置

打开 `miniprogram/config.js`，填两行：

```js
CLOUD_ENV: 'cloud1-d2g83jh3td8664c67',   // 实际环境 ID（只有一个环境时也可以留空）
CLOUD_FUNCTION: 'osurvey',            // 云函数名，填了它就代表「走云开发」
```

保存后重新编译小程序。首页「后端」那一行应该显示 **云开发（云函数 osurvey）**。

---

## 3. 上传云函数

1. 开发者工具左侧资源管理器里会出现 `cloudfunctions` 目录（如果没有，点右上角「刷新」或确认第 1 步打开的是根目录）。
2. 在 `osurvey` 上**右键** → **「上传并部署：云端安装依赖（不上传 node_modules）」**。
   > 第一次要装 exceljs，约 1~2 分钟，别急着关窗口。

---

## 4. 把云函数超时改成 20 秒（很重要！）

云函数**默认 3 秒**就超时，冷启动 + 导出 Excel 一定不够。

云开发控制台 → **云函数** → `osurvey` → **配置** → 执行超时时间改成 **20 秒** → 保存。

> 实测：在云函数目录里放 `config.json` 写 `"timeout": 20` **不生效**，只能在这个控制台里改。
> 以后若发现又变回 3 秒（例如重新部署过），回来再改一次即可。

---

## 5. 建数据库集合，并把权限收紧

云开发控制台 → **数据库** → 新建集合，共 5 个：

| 集合 | 存什么 |
|---|---|
| `survey` | 问卷 |
| `answer` | 答卷 |
| `visit` | 打开记录 |
| `survey_group` | 问卷 ↔ 群（多群模型） |
| `group_name` | 群名历史 |

每个集合的**权限**都选 **「仅管理端可读写」**（小程序端不直接读库，全部经云函数，所以越严越好）。

> 没建也没关系：云函数第一次跑 `admin/importSeed` 时会自动创建。

---

## 6. 把旧数据搬过来（真实问卷「结合剂」在这）

1. 在电脑上跑（只读 SQL Server，不会改任何东西）：
   ```
   cd D:\WORK\Survey-System\server
   node test\export-seed.js
   ```
   会生成 `cloudfunctions\osurvey\seed.json`。
2. 重新上传一次云函数（因为它要带上 seed.json）。
3. 云开发控制台 → **云函数** → `osurvey` → **云端测试** → 把测试参数填成：
   ```json
   { "method": "POST", "path": "/admin/importSeed" }
   ```
   点「运行」。看到 `{"statusCode":200,"data":{"ok":true,...}}` 就成了。
   > 这个动作是**幂等**的：重复运行只会跳过已存在的记录，不会重复、更不会删数据。
4. 搬完之后建议删掉 `cloudfunctions\osurvey\seed.json` 再上传一次（免得真实数据一直躺在云函数包里）。

**旧问卷编号不会变**：原来 `?sid=8` 的分享链接、旧卡片，搬到云之后还是 8，照样打得开。

## 7. 验证清单

| 检查 | 怎么做 | 期望 |
|---|---|---|
| 云函数活着 | 控制台云端测试 `{"method":"GET","path":"/health"}` | `statusCode:200`，`db.counts` 里 5 个集合都有数字 |
| 小程序连得上 | 打开小程序首页 | 「已登录」+ 显示 openid；「后端」显示云开发 |
| 建问卷 | 管理端 → 新建问卷 | 成功，列表里能看到 |
| 作答 | 从首页/卡片进问卷作答提交 | 提交成功，再提交一次提示「一人限一份」 |
| 统计与导出 | 统计页 → 导出 CSV / Excel | CSV 能复制，Excel 能打开 |
| 群绑定 | 把问卷卡片**发到微信群里**，从群里的卡片点进去 | 提示「已识别本群并加入问卷」 |

| 发布后改题 | 问卷详情页点「编辑题目」，改完点「保存修改」 | 保存成功，作答页看到新题 |
| 删除问卷 | 问卷详情页最底下点「删除这份问卷」 | 二次确认后删除，列表里消失 |
| 清理旧数据 | 问卷列表底部点「清理 365 天前的旧答卷」 | 提示已清理的答卷数 |
| 小程序码 | 问卷详情页点「小程序码」 | 弹出二维码图片，长按可保存/转发；朋友扫码直接进答题页（仅「开放作答」模式） |
| 切作答范围 | 问卷详情页点「改為『開放作答』／『綁定群組』」 | 二次确认后切换；画布上的提示随模式变化 |

> 「小程序码」走云调用 `wxacode.getUnlimited`（免 access_token），权限声明在
> `cloudfunctions/osurvey/config.json` → `permissions.openapi`。
> 每次上传云函数会按该配置刷新权限，**有约 10 分钟缓存**：刚传完若提示 `-604101 no permission`，等 10 分钟再试。
> 扫码不携带群信息（没有 shareTicket）→ 「绑定群组」的问卷扫码进来会在提交时被挡，请先用「改为开放作答」。

> 群里那条链路（openGId）只有**真机 + 真群**才走得通；开发者工具/游客模式拿不到真实群标识，
> 那属于正常现象，不是 bug。

| 想改什么 | 改哪里 |
|---|---|
| 后端逻辑（题目校验、评分、统计、导出、路由） | `cloudfunctions/osurvey/` 里的 `router.js` / `lib/*.js`，改完**重新上传云函数** |


## 10. 常见报错对照

| 现象 | 原因 / 解法 |
|---|---|
| `cloud init is not called` | `miniprogram/config.js` 的 `CLOUD_FUNCTION` 没填 / 没重新编译 |
| `FunctionName parameter could not be found` | 云函数名写错，应当是 `osurvey`；或第 3 步没上传成功 |
| 云函数报 `DATABASE_COLLECTION_NOT_EXIST` | 第 5 步的集合没建；跑一次 `admin/importSeed` 会自动建 |
| 云函数报 `timed out` / 前端一直转圈 | 第 4 步超时时间还是 3 秒 |
| 导出 Excel 报「这份问卷较大」 | 改用「导出 CSV」（云函数回包不能太大） |
| 首页显示「未登录」+ 一长串错误 | 把错误原样发出来：大概率是环境 ID 填错或云函数没上传 |
| 从群卡片进来提示「缺少分享信息」 | 不是从群卡片进的（比如从聊天记录/朋友圈）；或该群未绑定时用开放作答模式 |
| 云开发控制台一直「正在加载中」/「获取账号信息失败」 | 机器上开着代理（鹿语云、Clash 等）把开发者工具连微信的接口挡住了。解法：把微信/腾讯域名加进用户级环境变量 `NO_PROXY`（`weixin.qq.com;qq.com;tencent.com;myqcloud.com;servicewechat.com;gtimg.cn;...`），或临时退出代理再打开开发者工具 |
| 部署报「当前函数处于Creating状态，无法进行此操作」 | 上一次创建还没完成，等 10~30 秒再点一次部署即可 |

看日志：云开发控制台 → 云函数 → `osurvey` → **日志**，每次调用都有 `[osurvey] GET /surveys/8 → 200 (12ms)` 这样的记录。

## 11. 想切回自架版（备用）

`miniprogram/config.js` 里把 `CLOUD_FUNCTION`（必要时连 `CLOUD_ENV`、`CLOUD_SERVICE`）清空，
就会回到 `wx.request + API_BASE`（`https://interior.topmix.net/...`）那条老路。后端代码一直都在 `server/`。
